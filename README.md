# Harness Git 可视化插件

适配 **DeepSeek Harness 0.2.1-rc.2**，在会话右侧标签页提供 Git 仓库面板。

## 功能

- 按当前会话自动选择项目，也可切换到 Harness 已登记的其他工作区。
- 展示当前分支、工作区状态、已暂存和未暂存文件。
- 展示多分支提交图、提交说明和提交中的文件差异；历史可逐步加载至 500 条。
- 查看带行号的文本差异、未跟踪文件预览和二进制文件提示。
- 单个或批量暂存、取消暂存；填写说明后提交暂存区内容。
- 选择本地分支并确认后切换；冲突由 Git 拒绝并显示原因。
- 仓库 HEAD 在操作前已变化时要求刷新，避免基于旧提交执行操作。
- 文件和提交搜索、文件多选与批量暂存，筛选后的操作仅针对匹配项。
- 统一 / 并排差异、自动换行、修改位置跳转、行数统计与复制差异。
- 按项目保存提交说明草稿，支持 Ctrl / Cmd + Enter 提交。
- 窄侧栏使用列表与详情切换；暂存后保留当前文件，操作完成后刷新并反馈。

## 使用

1. 安装并启用组合包后，通过应用菜单完全退出、重新打开 Harness 桌面版。
2. 打开一个属于 Git 项目的会话，展开右侧面板。
3. 点击新标签页的 **Git 仓库** 卡片。
4. 在“工作区”中查看和暂存改动，在“提交历史”中浏览提交图。

切换分支：在“提交历史”的“查看分支”下拉框选择已有本地分支，再点击“切换”并确认。
远程分支可用于查看历史。

提交使用你自己的 Git 用户身份、提交钩子和签名配置。Git 缺失、用户身份未配置、
钩子失败、签名失败或工作区冲突时，面板会显示对应错误。

## 安装与卸载

桌面版进入应用内的“插件”安装页，输入这个 GitHub 安装地址：

```text
git+https://github.com/charlesjson/dsh-git-visual.git#v0.2.0
```

仓库包含 `dist/` 运行文件，安装时无需手动编译源码。桌面版的专有 `desktop` profile 应通过桌面应用自身管理。
也可以直接安装 [GitHub Release 安装包](https://github.com/charlesjson/dsh-git-visual/releases/download/v0.2.0/dsh-git-visual-0.2.0.tgz)。

Web 版可使用其插件页，或运行：

```sh
dsh plugin --profile web add "git+https://github.com/charlesjson/dsh-git-visual.git#v0.2.0"
```

Web 和桌面版共享会话时，插件仍分别安装到各自 profile。
在插件页关闭或移除本组合包，再重启即可卸载。

## 交互

窄面板中点击文件或提交进入详情，点击左上角返回按钮回到列表；宽面板同时显示两者。
文件列表显示文件名、所在目录和中文状态，可勾选单个或一组文件，再执行批量操作。
搜索时，“暂存匹配项”只处理当前匹配的文件，已勾选项的操作会明确显示数量。

提交说明草稿保存在当前浏览器窗口的 sessionStorage 中，按工作区隔离。提交成功后清除对应草稿。
状态刷新失败时保留当前内容，并暂停写操作，刷新成功后再继续。

快捷键只在 Git 面板中生效：`/` 聚焦搜索、`Alt+R` 刷新、方向键移动列表焦点、
`Esc` 返回列表或关闭切换分支对话框，提交说明框中的 `Ctrl/Cmd+Enter` 提交暂存区。

## 构建和验证

```sh
npm ci --ignore-scripts
npm test
npm pack
```

发布前执行测试和构建，并提交更新后的 `dist/`。CI 会检查运行文件与源码构建结果是否一致。

已覆盖临时真实 Git 仓库的分支合并、首次提交、改名、特殊文件名、暂存与取消暂存、
提交、冲突切换、旧 HEAD 拒绝，以及 Harness Gateway 调用和界面交互。

浏览器预览使用独立的临时测试仓库：

```sh
npm run preview
```

预览地址打印在终端中；关闭预览进程时清理测试仓库。此页面与插件使用相同的面板和 Git 服务。

## 实现

宿主插件通过 Harness 的认证 Gateway 暴露 `gitVisual/request`，只接受已登记工作区的标识，
不接收任意宿主目录。浏览器部分复用 Harness 的 React 实例，注册原生右侧标签页。

所有 Git 参数通过子进程参数数组传递，不经过 shell。读差异时关闭外部 diff 和 textconv，
读取状态时关闭 fsmonitor。仓库写操作按仓库串行执行，并检查界面显示的 HEAD。
提交只操作暂存区；暂存和取消暂存使用选定文件路径，切换分支使用已有本地分支。

文本差异最多读取约 2 MB，界面最多渲染 2000 行；大文件会显示截断提示。
提交图与历史差异默认比较合并提交的第一个父提交。
